## How to Create Missing Assets

### 1. ItemView.prefab
In Unity Editor:
1. Go to `Assets/Prefabs/Inventory/`
2. Create a new UI prefab named `ItemView`
3. Structure: Root GameObject > RectTransform > CanvasGroup > Image (background) + Text (name) + Image (icon)
4. Add the `ItemView` component from `Assets/Scripts/Inventory/ItemView.cs`
5. Assign the Icon and NameText fields in the Inspector
6. Save the prefab

### 2. ScriptableObject .asset files
In Unity Editor:
1. Create each ScriptableObject via `Create > Roguelike/` menu
2. Or run the `AssetSetup` menu item: `Tools > Setup ItemView Prefab and Assets`
3. This creates sample SO assets and the ItemView.prefab

### 3. WaveDataSO assets
In Unity Editor:
1. Create `Wave_` assets via `Create > Roguelike > Wave Data`
2. Assign Enemy, EquipmentDropPool, and TokenDropPool
3. Reference these in GameManager's WaveManager component

## Verification
After setup, verify:
1. Game enters Play mode without errors
2. InventorySystem shows 6x6 grid
3. TokenRewardTray shows 5x1 grid
4. Combat starts when pressing the ReadyPanel Start button
5. Enemy attacks player each tick
6. Defeating enemy triggers reward phase

## Troubleshooting
- If `ItemView.prefab` is missing: Recreate it as described above
- If SO assets are missing: Use the AssetSetup menu or create them manually
- If references are null: Assign the relevant GameObjects/prefabs in the Inspector
